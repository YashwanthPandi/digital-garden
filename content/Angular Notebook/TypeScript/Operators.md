---
title: Operators
tags:
  - TypeScript
---

- **Arithmetic:** `+` addition, `-` minus, `*` multiply, `%` modulus
- **Assignment:** `=`, or `+=`, `-=`, `*=`, `/=`, `%=`
- **Comparison:** `==` vs `===` (`===` checks data type + value), `>` greater, `<` less (`x < 4`: x is less than 4)
- **Logical:** `&&` AND (both true → true), `||` OR (true or false → true), `!` NOT (opposite)
- **Unary:** `++`, `--`, `typeof` (`a++`, `b++`)
- **Ternary / conditional:** shortcut of if-else. If the condition is true it gives result 1, if false result 2.
