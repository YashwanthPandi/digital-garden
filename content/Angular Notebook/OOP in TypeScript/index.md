**What is OOPs & advantage against functional programming?**
A paradigm built around **objects & methods**. Objects = data structures that bundle state; methods have behaviour (logic). Advantage: code reusability.

**Main concepts:** Classes & objects · Encapsulation (data security) · Inheritance (code reusability) · Polymorphism (multiple forms) · Abstraction (hide complexity)

## Class members

- **Properties** – the variables that [cut off]
- **Method** – a block of code that performs a specific task
- **Constructor** – also a method, executed when the class is created
- **Access modifiers** – set the visibility of class members
