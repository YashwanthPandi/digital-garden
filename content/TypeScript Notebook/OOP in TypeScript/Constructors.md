class (father) + constructor (mother) = object (child)

A special method that initializes objects of a class; used to initialize the properties of an object.

- **Types:** default constructor (no parameters; created by TS automatically) and parameterized constructor (accepts parameters)
- **What happens when no constructor is defined?** The compiler will automatically create one.
